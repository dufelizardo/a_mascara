# ADR-010: Modelagem de Antagonistas e Criaturas Sobrenaturais

- **Status:** Proposto
- **Data:** 2026-09-14
- **Decisores:** [Seu Nome / Equipe]
- **Contexto Técnico:** Modelagem dos antagonistas, criaturas sobrenaturais e ameaças do Mundo das Trevas
- **Tags:** `antagonistas`, `caçadores`, `lobisomens`, `magos`, `fadas`, `aparições`, `demônios`, `bestiário`, `vampiro-a-mascara`
- **Depende de:** ADR-002 (Mundo das Trevas), ADR-004 (Ficha de Personagem), ADR-006 (Resolução), ADR-007 (Sistemas Dramáticos)

---

## 1. Contexto

O **Capítulo Nove: Os Outros** expande o Mundo das Trevas para além dos vampiros. Ele apresenta as **outras criaturas sobrenaturais** que habitam as sombras, bem como os **antagonistas mortais** que caçam os Membros. Os vampiros não estão sozinhos — eles compartilham o mundo com seres tão terríveis (ou mais) do que eles próprios.

Este capítulo cobre:

- **Caçadores de Bruxas:** A Sociedade de Leopoldo (Inquisição moderna), agentes do governo (ASN, FBI, CIA), o Arcano.
- **O Governo dos EUA:** Agências governamentais que investigam o sobrenatural.
- **Lobisomens (Lupinos):** Os metamorfos, inimigos ancestrais dos vampiros.
- **Magos:** Mortais com poder de alterar a realidade.
- **Fadas (Changelings):** Seres de outro mundo, enigmáticos e perigosos.
- **Aparições:** Fantasmas, espectros e almas penadas.
- **Demônios:** Entidades infernais que possuem mortais e corrompem a realidade.
- **Bestiário:** Estatísticas de animais comuns (cães, gatos, lobos, cavalos, etc.).

A plataforma precisa modelar esses antagonistas não como **inimigos genéricos**, mas como **criaturas com personalidade, motivações e regras próprias**. Cada tipo de antagonista representa uma **ameaça diferente** e uma **oportunidade narrativa diferente**:

- **Caçadores:** Ameaça mortal que expõe a Máscara.
- **Lobisomens:** Ameaça física devastadora; inimigos ancestrais.
- **Magos:** Ameaça imprevisível; poder incompreensível.
- **Fadas:** Ameaça psicológica; enigmas e bargains.
- **Aparições:** Ameaça espiritual; ligadas ao passado.
- **Demônios:** Ameaça corruptora; perigo para a alma.
- **Animais:** Presas, aliados ou ameaças menores.

Este ADR define **como modelar os antagonistas e criaturas sobrenaturais** na plataforma.

---

## 2. Decisão

Decidimos modelar os antagonistas e criaturas sobrenaturais através de **oito módulos independentes**, cada um representando um tipo de ameaça. Cada módulo inclui fichas de dados, regras especiais e ferramentas para o Narrador.

### 2.1. Modelagem Geral de Antagonistas

**Decisão:** Todos os antagonistas são modelados a partir de uma **entidade base**, com campos comuns e campos específicos.

**Estrutura de Dados Base:**

```
Antagonista (Antagonist)
├── id: UUID
├── tipo: enum                          # Caçador | Lupino | Mago | Fada | Aparição | Demônio | Animal
├── subtipo: string                     # Ex: "Sociedade de Leopoldo", "Inquisidor", "Lupino Veterano"
├── nome: string
├── descrição: text                     # Visão geral
├── aparência: text                     # Descrição visual
├── personalidade: text                 # Natureza, Comportamento
├── motivações: [Motivação]             # O que o antagonista quer
├── fraquezas: [Fraqueza]               # Vulnerabilidades
├── poderes: [Poder]                    # Habilidades especiais
├── estatísticas: Estatísticas          # Atributos, Habilidades, Disciplinas
├── equipamento: [Item]                 # Armas, itens, artefatos
├── relações: [Relação]                 # Relações com outros NPCs
├── histórico: text                     # Passado do antagonista
├── segredos: [Segredo]                 # Visíveis apenas ao Narrador
└── status: enum                        # Ativo | Morto | Desconhecido
```

**Funcionalidades:**

- **Catálogo de Antagonistas:** Uma biblioteca de antagonistas pré-criados (baseados no Capítulo Nove).
- **Criação de Antagonistas:** O Narrador pode criar antagonistas customizados.
- **Importação/Exportação:** Antagonistas podem ser exportados (JSON) e compartilhados.
- **Ativação em Cena:** O Narrador pode ativar um antagonista em uma cena; a plataforma exibe sua ficha e permite rolar dados.

### 2.2. Módulo de Caçadores

**Decisão:** Modelar os **Caçadores** como antagonistas mortais, com organizações, táticas e equipamentos específicos.

**Organizações a Implementar:**

| Organização | Descrição | Foco |
|-------------|-----------|------|
| **Sociedade de Leopoldo** | Inquisição moderna; católicos e ecumênicos. | Erradicar vampiros e outras entidades sobrenaturais. |
| **Governo dos EUA (ASN)** | Agência de Segurança Nacional; usa caoscópios. | Monitorar e conter ameaças sobrenaturais. |
| **FBI (DECAE)** | Departamento de Casos Especiais. | Investigar atividades paranormais. |
| **CIA** | Agência de Inteligência. | Espionagem sobrenatural. |
| **O Arcano** | Sociedade secreta de eruditos. | Estudar e conter o sobrenatural. |
| **Caçadores Independentes** | Indivíduos ou pequenos grupos. | Vingança pessoal, fé, curiosidade. |

**Estrutura de Dados (Caçador):**

```
Caçador (Hunter)
├── id: UUID
├── organização: UUID                   # Referência à organização
├── nome: string
├── patente: string                     # Ex: "Inquisidor", "Agente", "Erudito"
├── descrição: text
├── motivação: string                   # Por que caça vampiros
├── fé: int                             # Fé Verdadeira (0-5)
├── humanidade: int                     # 1-10
├── força_vontade: int                  # 1-10
├── atributos: Atributos
├── habilidades: Habilidades
├── equipamento: [Item]                 # Armas, estacas, crucifixos, etc.
├── táticas: [Tática]                   # Como caça
├── fraquezas: [Fraqueza]               # Vulnerabilidades
├── segredos: [Segredo]
└── status: enum
```

**Fé Verdadeira:**

A Fé Verdadeira é uma Característica especial (0-5) que permite a um mortal repelir vampiros. A plataforma modela isso como um **poder passivo**:

| Nível | Efeito |
|-------|--------|
| 1 | Teste de Fé (dificuldade = Força de Vontade do vampiro); sucesso = vampiro recua. |
| 2 | + Resiste à Dominação gastando Força de Vontade. |
| 3 | + Sente a presença de vampiros. |
| 4 | + Imune a carniçais; imune a Disciplinas mentais. |
| 5 | + Causa terror e dor física a vampiros. |

**Equipamento de Caçadores:**

| Item | Efeito |
|------|--------|
| **Estaca** | Pode paralisar um vampiro se enfiada no coração. |
| **Crucifixo** | Repele vampiros se o portador tiver Fé Verdadeira. |
| **Água Benta** | Causa dano agravado a vampiros. |
| **Bengala-Espada** | Arma disfarçada; causa dano letal. |
| **Maçarico** | Causa dano agravado (fogo). |
| **Caoscópio** | Detecta vampiros e carniçais. |

**Táticas de Caçadores:**

| Tática | Descrição |
|--------|-----------|
| **Emboscada Diurna** | Ataque ao refúgio durante o dia. |
| **Cerco** | Cercar o refúgio e forçar o vampiro a sair. |
| **Armadilha** | Usar iscas para atrair o vampiro. |
| **Fogo** | Usar fogo para destruir o refúgio. |
| **Fé** | Usar Fé Verdadeira para repelir o vampiro. |
| **Tecnologia** | Usar caoscópios e armas modernas. |

### 2.3. Módulo de Lobisomens (Lupinos)

**Decisão:** Modelar os **Lobisomens** como antagonistas sobrenaturais devastadores, com poderes e fraquezas específicas.

**Poderes e Fraquezas dos Lupinos:**

| Aspecto | Descrição |
|---------|-----------|
| **Formas** | Humana, Lobo, Homem-Lobo (Crino), Crino de Combate. |
| **Atributos Físicos** | Duplicados na forma de Crino. |
| **Delírio** | Mortais que veem um Lupino em Crino ficam aterrorizados. |
| **Ações Múltiplas** | Podem realizar 2-6 ações por turno. |
| **Regeneração** | Curam 1 nível de vitalidade por turno. |
| **Dano Agravado** | Garras e presas causam dano agravado. |
| **Fraqueza: Prata** | Dano de prata não é absorvido nem regenerado. |
| **Gnose** | Recurso espiritual (como pontos de sangue). |
| **Poderes Místicos** | Rituais e dons espirituais. |

**Estrutura de Dados (Lupino):**

```
Lupino (Werewolf)
├── id: UUID
├── tribo: string                       # Ex: "Fianna", "Get of Fenris", "Glass Walkers"
├── auspício: string                    # Ex: "Ragabash", "Theurge", "Philodox"
├── nome: string
├── descrição: text
├── formas: [Forma]                     # Humana, Lobo, Crino, Crino de Combate
├── atributos: Atributos                # Atributos humanos
├── atributos_crino: Atributos          # Atributos na forma de Crino
├── habilidades: Habilidades
├── dons: [Dom]                         # Poderes espirituais
├── rituais: [Ritual]
├── gnose: int                          # 0-10
├── força_vontade: int                  # 1-10
├── humanidade: int                     # 1-10
├── equipamento: [Item]
├── fraquezas: [Fraqueza]               # Prata, etc.
├── segredos: [Segredo]
└── status: enum
```

**Estatísticas de Exemplo:**

| Tipo | Força | Destreza | Vigor | Gnose | Força de Vontade |
|------|-------|----------|-------|-------|------------------|
| **Lupino Adolescente** | 3 | 3 | 3 | 4 | 5 |
| **Lupino Veterano** | 4 | 4 | 4 | 6 | 7 |
| **Metamorfo Ancião** | 5 | 4 | 5 | 8 | 9 |

**Nota sobre o Sangue Lupino:**

O sangue de um Lupino é extremamente potente. Um vampiro que se alimenta de um Lupino ganha **o dobro de pontos de sangue**, mas fica **mais suscetível ao frenesi** (+1 dificuldade por ponto de sangue lupino consumido).

### 2.4. Módulo de Magos

**Decisão:** Modelar os **Magos** como antagonistas mortais com poder de alterar a realidade, mas com a limitação do **Paradoxo**.

**Poderes e Fraquezas dos Magos:**

| Aspecto | Descrição |
|---------|-----------|
| **Magia** | Podem alterar a realidade (simulada como Disciplinas). |
| **Paradoxo** | Magias óbvias causam Paradoxo (resultados catastróficos). |
| **Quintessência** | Recurso mágico (como pontos de sangue). |
| **Mortais** | Não absorvem dano letal ou agravado sem proteção. |
| **Imunidade ao Abraço** | O Abraço destrói o poder de um mago. |
| **Laço de Sangue** | Magos não são imunes ao laço de sangue. |

**Facções de Magos:**

| Facção | Descrição | Foco |
|--------|-----------|------|
| **Ordem de Hermes** | Magos herméticos; tradição clássica. | Conhecimento, magia formal. |
| **Xamãs e Iogues** | Magos espirituais; tradição primitiva. | Espíritos, cura, transformação. |
| **Techno-Aberrações** | Magos da hiper-tecnologia. | Tecnologia, cibernética, hacking. |
| **Feiticeiros** | Magos do sangue; tradição sombria. | Magia do sangue, rituais. |

**Estrutura de Dados (Mago):**

```
Mago (Mage)
├── id: UUID
├── facção: UUID                        # Referência à facção
├── nome: string
├── descrição: text
├── arete: int                          # Nível de maestria mágica
├── quintessência: int                  # 0-10
├── força_vontade: int                  # 6-10
├── humanidade: int                     # 1-10
├── atributos: Atributos
├── habilidades: Habilidades
├── esferas: [Esfera]                   # Esferas de magia (Correspondência, Entropia, Forças, Vida, Matéria, Mente, Prime, Espírito, Tempo)
├── disciplinas_equivalentes: [Disciplina] # Poderes simulados
├── equipamento: [Item]                 # Focos mágicos, artefatos
├── paradoxo: int                       # Acumulado
├── fraquezas: [Fraqueza]
├── segredos: [Segredo]
└── status: enum
```

**Estatísticas de Exemplo:**

| Tipo | Arete | Quintessência | Força de Vontade |
|------|-------|---------------|------------------|
| **Praticante Jovem** | 2 | 10 | 5 |
| **Mago Experiente** | 4 | 12 | 9 |
| **Alto Mago** | 6 | 15 | 10 |

### 2.5. Módulo de Fadas (Changelings)

**Decisão:** Modelar as **Fadas** como antagonistas enigmáticas e imprevisíveis, com regras próprias.

**Poderes e Fraquezas das Fadas:**

| Aspecto | Descrição |
|---------|-----------|
| **Glamour** | Recurso mágico (como pontos de sangue). |
| **Aparência** | Podem esconder sua forma feérica dos mortais. |
| **Fraqueza: Ferro Frio** | Dano de ferro frio não é absorvido. |
| **Cura** | Curam-se como mortais. |
| **Aversão a Vampiros** | Evitam os mortos-vivos. |

**Tipos de Fadas:**

| Tipo | Descrição |

### 2.6. Módulo de Aparições

**Decisão:** Modelar as **Aparições** (fantasmas, espectros) como antagonistas incorpóreos, com regras próprias.

**Poderes e Fraquezas das Aparições:**

| Aspecto | Descrição |
|---------|-----------|
| **Incorpóreo** | Invisíveis; afetam o mundo físico com esforço. |
| **Paixão** | Recurso emocional (como pontos de sangue). |
| **Grilhões** | Objetos ou pessoas que os ligam ao mundo. |
| **Mortalha** | Barreira entre vivos e mortos. |
| **Espectros** | Aparições malignas e perigosas. |

**Tipos de Aparições:**

| Tipo | Descrição |
|------|-----------|
| **Recém-Falecido** | Aparição inexperiente; ligada ao mundo mortal. |

| **Alma Antiga** | Aparição poderosa; séculos de existência. |

**Estrutura de Dados (Aparição):**

├── grilhões: [Grilhão]                 # Objetos/pessoas importantes

**Poderes e Fraquezas dos Demônios:**

| Aspecto | Descrição |

## 3. Consequências

### 3.1. Positivas

- **Riqueza de Antagonistas:** A plataforma oferece uma vasta gama de antagonistas, cada um com regras próprias.
- **Fidelidade ao Material Original:** Todos os antagonistas do Capítulo Nove são modelados.
- **Ferramentas para o Narrador:** O Narrador pode criar, organizar e ativar antagonistas facilmente.
- **Variedade Narrativa:** Cada tipo de antagonista oferece diferentes oportunidades narrativas.
- **Bestiário Integrado:** Animais podem ser usados como presas, aliados ou ameaças.
- **Base para ADRs Futuros:** A modelagem de antagonistas estabelece as fundações para o Sistema de Linhagens (ADR-011) e o Sistema de Qualidades/Defeitos/Carniçais (ADR-012).

### 3.2. Negativas

- **Complexidade de Implementação:** Modelar oito tipos de antagonistas com regras próprias é um esforço significativo.
- **Balanceamento:** Garantir que cada antagonista seja desafiador, mas não injusto, é um desafio de design.
- **Curva de Aprendizado:** Novos Narradores podem se sentir sobrecarregados com tantas opções.
- **Manutenção:** Novos antagonistas (de suplementos futuros) precisam ser incorporados.
- **Performance:** A ativação de múltiplos antagonistas em uma cena pode impactar a performance.

### 3.3. Alternativas Descartadas

| Alternativa | Motivo da Rejeição |
|-------------|-------------------|
| **Apenas Vampiros como Antagonistas** | Ignoraria a riqueza do Mundo das Trevas. |
| **Antagonistas Genéricos** | Perderia a identidade de cada tipo de criatura. |
| **Sem Bestiário** | Perderia a oportunidade de usar animais como presas ou aliados. |
| **Sem Ferramentas de Criação** | Limitaria a criatividade do Narrador. |
| **Sem Estatísticas Detalhadas** | Dificultaria a resolução de combates e interações. |
